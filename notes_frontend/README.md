# Note Keeper – Angular

A modern, light-themed notes app built with Angular. Features include:

- Add new note
- Edit existing note
- Delete note
- View all notes
- Search notes (sidebar, instant filtering)
- Responsive layout with sidebar/main area
- Modern light UI (Primary: #2196f3, Accent: #f44336, Secondary: #ffc107)

## Development
Start the development server:
```
ng serve
```
Visit [http://localhost:4200/](http://localhost:4200/)

## Structure

- **Sidebar**: Navigate, search, add notes.
- **Main Content**: Edit/view notes or see the list.
- **REST API**: Expects a backend at `/api/notes`.
